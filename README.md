Garbanzo Quest – French Translation

This is the **French translation** of Garbanzo Quest.

# 📥 Installation

Follow these steps to install the translation:

1. Click the green **`Code`** button at the top of this GitHub page.
2. Click **`Download ZIP`**.
3. Extract the downloaded `.zip` file.
4. Open the extracted folder.
5. Find the **`French`** folder.
6. Copy the entire **`French`** folder.
7. Go to your Garbanzo Quest game folder.
8. Open:

   `Assets/Dials/`

9. Paste the **`French`** folder inside the `Dials` folder.

Your files should look like this:

```text
Garbanzo Quest/
└── Assets/
    └── Dials/
        └── French/
            ├── ...
            └── ...
